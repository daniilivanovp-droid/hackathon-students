# Концепция дашборда продаж

**Для кого:** руководитель коммерческого направления Capibara. Дашборд помогает видеть, какие категории и продавцы дают выручку, как меняются число доставленных заказов и средний чек, где появляются повторные покупки. По нему можно выбрать категории для продвижения и продавцов, которым нужна поддержка.

**Срезы:** месяц оформления заказа, категория, продавец и штат продавца. Денежные показатели учитывают только заказы со статусом `delivered`; дата относится к `core.orders.purchased_at`.

| Показатель | Формула | Уровень расчёта | Источник |
| --- | --- | --- | --- |
| Выручка | Сумма `price` доставленных товарных позиций; доставка исключена. | Позиция заказа. | `core.order_items` + `core.orders`; `mart.monthly_sales`, `mart.seller_sales`, `mart.category_sales`. |
| Доставленные заказы | `count(distinct order_id)` со статусом `delivered`. | Заказ. | `mart.order_financials`; для срезов продавца и категории — позиции с уникальным `order_id`. |
| Единицы товара | Число строк доставленных `order_items`. | Позиция заказа. | `core.order_items` + `core.orders`; `mart.seller_sales`. |
| Средний чек | Сумма `(price + freight_value)` по доставленным заказам / число этих заказов. | Заказ. | `mart.order_financials`. |
| Доля категории в выручке | Выручка категории / выручка всех категорий в том же периоде × 100%. | Категория в выбранном периоде. | `mart.category_sales`; при фильтре периода пересчитывать из `core.order_items` + `core.orders` + `core.products`. |
| Доля повторных покупателей | Число `customer_unique_id` с двумя и более оформленными заказами / число `customer_unique_id` с хотя бы одним × 100%; статус заказа не фильтруется. | Покупатель в выбранном периоде. | `mart.customer_orders` для всего периода; для фильтра по месяцам пересчитывать из `mart.order_financials` без фильтра `is_revenue_order`. |

## Что нельзя складывать

- Средние чеки и доли по группам не суммируются: общий показатель надо заново рассчитывать из сумм и количества.
- Один заказ может содержать товары разных продавцов и категорий. Поэтому числа заказов из строк по продавцам или категориям нельзя складывать в общий итог.
- Число уникальных покупателей по месяцам также нельзя складывать: один человек может купить в нескольких месяцах.
- Выручку и единицы товара можно складывать по непересекающимся месяцам, продавцам и категориям, если каждая позиция отнесена ровно к одной группе.
