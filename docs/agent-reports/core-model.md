# Отчёт агента: модель `core` и витрины

Модель проверена запросами `SELECT` в работающем PostgreSQL 16 через Docker. Для C-03 выполнены два временных теста в отдельных транзакциях с `ROLLBACK`; полную сборку повторно не запускал и общий чек-лист не менял. Испытание отката всей сборки остаётся задачей Q-05.

| Задача | Что сделано | Как проверено | Что осталось |
| --- | --- | --- | --- |
| C-01 | Сохранил восемь таблиц с прежними ключами. Почтовый префикс теперь текст, а товар позиции и категория товара обязательны. | В PostgreSQL есть 8 таблиц и PK у каждой; FK есть у всех зависимых таблиц. `zip_code_prefix` — `text`, деньги — `numeric`, дата заказа — `timestamp`, обязательные связи помечены `NOT NULL`. | Нет для проверки структуры. |
| C-02 | Добавил явную категорию `Non category`, два согласованных перевода и признак `translation_source` со значениями `source`, `manual`, `missing`. Товар без категории получает ключ этой записи. | В базе 32 951 товар, у всех есть категория; 610 относятся к `Non category`. В справочнике 71 перевод источника, 2 ручных и 1 пустая категория — всего 74. | Нет для проверки категорий. |
| C-03 | До удаления старой модели добавил проверки повторяющихся ключей и потерянных связей в `raw`. Остальные связи защищены PK/FK и обязательными полями. | В CSV не найдено повторов ключей и сирот; в базе 7 одноимённых таблиц `raw`/`core` имеют одинаковое число строк. В отдельной транзакции дубль `raw.orders.order_id` вызвал ошибку «Дубликат ключа в raw.orders: order_id», а позиция с неизвестным заказом — «Позиция без заказа в raw.order_items». После обоих `ROLLBACK` осталось 99 441 заказ и 112 650 позиций в `raw`, столько же в `core`; `mart.order_financials` доступна и содержит 99 441 строку. | Для C-03 больше ничего. Откат всей пересборки проверяется отдельно в Q-05. |
| M-01 | `mart.order_financials` даёт одну строку на заказ; число единиц считается по строкам позиций. | В базе 99 441 строка и 99 441 уникальный заказ; суммы строк и единиц равны 112 650, средний чек доставленного заказа — `159.88`. | Нет для проверки зерна и среднего чека. |
| M-02 | Продажи продавца считаются по его позициям; каждая позиция связана с категорией через товар. | Лидер продавцов имеет выручку `226 987.93`. В `mart.category_sales` 74 строки; сумма `13 221 498.11` равна сумме цен доставленных позиций, крупнейшая категория — `1 233 131.72`. | Нет для проверки контрольных сумм. |
| M-03 | `mart.customer_orders` считает количество и даты по всем оформленным заказам; выручку — только по доставленным. | Запрос к витрине дал 96 096 покупателей, 2 997 повторных и `3.12%`; отдельный подсчёт CSV дал те же числа. | Нет для проверки повторных покупок. |
| M-04 | `mart.monthly_sales` не ограничена 24 месяцами: она группирует все месяцы с заказами. | В базе 25 месяцев с сентября 2016 по октябрь 2018. Ряд отчёта содержит 24 месяца; один из них отсутствует в источнике и заполняется нулём, сумма отчёта — `13 221 498.11`. | Нет для проверки периода; запрос отчёта поддерживает отдельный агент. |
